# DevNexus AI 用户指南

本文档只说明当前产品里仍可直接使用的主流程。

## 基本使用路径

1. 打开聊天页面。
2. 输入问题或任务目标。
3. 如需文件上下文，上传文件。
4. 等待文件进入可用状态后再发送消息。

## 上传后会发生什么

系统会把文件处理拆成两条链路：

- 语义链路：用于摘要、引用、检索和上下文注入。
- 执行链路：用于把真实文件交给任务工作区和外部 runner 处理。

这两条链路可以同时存在，也可以只走其中一条。

## 如何理解文件状态

### 语义上下文
文件被成功解析后，可进入模型上下文，用于阅读、总结、引用和问答。

### 执行上下文
文件作为真实资产参与任务执行时，会进入执行上下文。这里强调的是文件本体可被处理，而不是模型是否已读懂内容。

## 文件任务如何运行

当前文件任务运行方式为：

1. 建立任务工作区。
2. 准备输入文件与模板文件。
3. 生成任务合同。
4. 优先运行 `runner.ps1`，其次运行 `runner.py`。
5. 收集输出并回灌为新的文件资产。

## 如何继续处理结果文件

结果文件可以重新加入当前会话，继续作为下一轮输入。

## 如何理解失败状态

- 解析失败：优先看附件与输入区里的失败原因。
- 任务失败：优先看任务状态、失败摘要和是否可重试。
